# stackof20 website

Static website prepared for https://stackof20.com. GitHub Pages deploys the main branch root. The rebrand remains on a draft branch for owner review; pushing this branch does not publish it. Do not merge or change the live Pages custom domain until the owner approves publication.

Edit index.html, privacy.html and support.html. Assets and the Hanken Grotesk font are served locally; the font license is assets/fonts/OFL.txt. The approved cream/purple design and 06B mark are retained. stackof20 is a product of BACS Tech, Inc., created by David Marcantonio. Support/privacy contact: hello@stackof20.com.

The owner purchased stackof20.com and verified it in GitHub. Verification reserves the Pages domain but does not configure hosting or HTTPS. CNAME contains the future custom domain for publication after approval; live Pages settings are unchanged.

The site has no analytics or tracking scripts. App screenshots and download links remain placeholders. For local review, serve this directory with a loopback HTTP server. The current review copy is available at http://127.0.0.1:8767/ on the development Mac.
